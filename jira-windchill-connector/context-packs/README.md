# Context Packs

Pre-assembled, scoped context for handing a task to an agent (or a new engineer)
without dumping the whole `docs/` tree into a window. Each pack states: the
mission, the exact docs to load, the invariants that must not be violated, the
definition of done, and the traps specific to that task.

Rule of thumb: if a pack needs more than four documents, the task is too big —
split it.
